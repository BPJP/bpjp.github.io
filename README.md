MotoGP Chat プライバシーポリシー
最終更新日：2026年11月8日
1. はじめに
MotoGP Chat（以下「本サービス」）は、MotoGPのライブ配信を視聴するユーザー同士がリアルタイムで交流するためのGoogle Chrome拡張機能です。
本サービスの運営者（以下「運営者」）は、ユーザーのプライバシーを尊重し、必要最小限の情報のみを取り扱います。
2. 取得・取り扱う情報
本サービスでは、ユーザー登録やアカウント認証を必要とせず、氏名、住所、メールアドレス、電話番号、Googleアカウント情報などを取得しません。
ただし、本サービスの機能提供および不正利用防止のため、以下の情報を取り扱います。
* ハンドルネーム： チャット上でユーザーを表示するために使用します。
* チャット投稿内容： メッセージを他の接続ユーザーに配信し、チャット履歴を提供するために使用します。
* 接続元IPアドレス： 同一ネットワークからの接続数制限や不正利用防止のために使用します。
また、本サービスは利用可能なページを判定するため、Chromeのタブ情報からページのURLおよびタイトルを確認します。この情報は利用条件の判定に使用するものであり、閲覧履歴として収集・保存したり、外部サーバーへ送信したりすることはありません。
3. 情報の利用目的
取り扱う情報は、以下の目的に限って使用します。
* リアルタイムチャット機能の提供
* チャット上でのハンドルネームおよび投稿内容の表示
* チャット履歴の提供
* 接続数および投稿頻度の制限
* 不正利用、迷惑行為およびサービスへの不正アクセスの防止
* サービスの安定運用および障害対応
上記以外の目的で情報を利用することはありません。
4. 情報の保存
チャット投稿内容は、チャット履歴の提供を目的として、直近50件をサーバー上に保存します。
ハンドルネームおよび投稿内容は、チャット参加者に表示されます。
接続元IPアドレスは、接続数制限および不正利用防止のために取り扱います。また、サーバーの運用ログに接続情報等が記録される場合があります。
本サービスが利用するRenderの無料プランでは、運用ログは最大7日間保持されます。ログの保持および削除は、Renderのサービス仕様に従います。
運営者は、取り扱う情報を利用目的に必要な範囲を超えて保持しません。
5. 第三者への提供および外部事業者の利用
運営者は、ユーザーの情報を販売したり、広告配信やマーケティングを目的として第三者に提供したりすることはありません。
ただし、本サービスの運営にはサーバーインフラ事業者（Render等）を利用しています。これらの事業者は、サービスの提供、維持および保護に必要な範囲で、通信情報やサーバー上のデータを取り扱う場合があります。
このようなインフラ事業者による取り扱いは、サービス運営に必要な範囲に限定されます。
また、法令に基づく正当な要請があった場合には、法令に従って必要な情報を開示することがあります。
6. 情報の安全管理
運営者は、取り扱う情報への不正アクセス、漏えい、改ざんおよび滅失を防止するため、合理的な安全管理措置を講じます。
本サービスとサーバー間の通信には、HTTPSおよびWSSによる暗号化通信を使用します。
7. 本ポリシーの変更
本ポリシーは、法令の改正や本サービスの機能変更等に応じて、必要に応じて改定することがあります。
変更後のプライバシーポリシーは、本サービスまたは運営者が指定するウェブサイト上に掲載した時点で適用されます。
